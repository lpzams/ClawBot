# Phase 1: 最小执行链 - 核心概念

## 学习目标

理解 AI Agent Harness 的最小执行路径，掌握依赖注入和确定性测试的实际应用。

## 核心概念

### 1. 什么是 Harness？

**定义：** Harness 是把大语言模型可靠运行起来的"外壳"或"线束"（wiring harness）。

**类比：**
- 汽车发动机（模型）需要线束来连接电路、传感器和控制系统
- AI 模型需要 Harness 来组织消息、管理状态、执行工具、限制风险

**Harness 负责什么：**
```
用户输入 -> [边界校验] -> [消息组装] -> 模型调用 -> [结果验证] -> 输出
```

**Harness 不负责什么：**
- ❌ 不知道你的业务逻辑（客服/代码审查/数据分析）
- ❌ 不绑定具体模型供应商（OpenAI/Claude/本地模型）
- ❌ 不决定用 CLI 还是 Web 界面

### 2. 为什么需要最小执行链？

**错误做法：**
```python
# ❌ 直接调用，没有边界
def chat(text):
    response = openai.chat(text)
    return response
```

**问题：**
- 空输入会浪费 API 调用
- 无法测试（必须联网）
- OpenAI API 变更时要改多处代码
- 难以切换到其他模型

**正确做法：**
```python
# ✅ 通过 Harness 隔离关注点
def chat(text):
    harness = Harness(model, system_prompt="...")
    return harness.run(text)  # 边界校验、消息组装都在这里
```

### 3. 依赖注入的最小用途

**什么是依赖注入？**
把依赖项（如模型）从外部传入，而不是在内部创建。

**ClawBot 的实现：**
```python
class Harness:
    def __init__(self, model: Callable, *, system_prompt: str = None):
        self.model = model  # 注入，不在内部 new 一个
        
    def run(self, prompt: str) -> str:
        messages = self._build_messages(prompt)
        return self.model(messages)  # 调用注入的模型
```

**好处：**
- 测试时注入 `FakeModel`
- 生产时注入 `OpenAICompatibleModel`
- 未来可以注入本地模型、远程 RPC、缓存装饰器...

### 4. Fake Model 与确定性测试

**为什么需要 Fake Model？**

```python
# ❌ 测试依赖真实 API
def test_agent():
    result = agent.run("hello")
    assert "greeting" in result.lower()  # 不确定，模型可能说任何话
```

**问题：**
- 💰 每次测试消耗 API 额度
- 🐌 网络延迟让测试慢
- 🎲 不确定性：同样输入可能不同输出
- ❌ 无网络时测试失败

**用 Fake Model 测试：**
```python
def fake_model(messages):
    return f"Fake: {messages[-1]['content']}"

def test_agent():
    harness = Harness(fake_model)
    result = harness.run("hello")
    assert result == "Fake: hello"  # 确定性断言
```

**好处：**
- ✅ 免费、快速、确定
- ✅ 测试的是"消息组装逻辑"，不是模型质量
- ✅ 离线可运行

### 5. 红灯-绿灯-重构循环

ClawBot 的 Phase 1 采用 TDD（测试驱动开发）：

**步骤 1：红灯（先写失败测试）**
```python
# tests/test_agent.py
def test_run_agent():
    result = run_agent("hello", fake_model)
    assert result == "Fake: hello"
```
运行 → `ModuleNotFoundError` → 红灯 ✅

**步骤 2：绿灯（最小实现）**
```python
# clawbot/agent.py
def run_agent(prompt, model):
    messages = [{"role": "user", "content": prompt}]
    return model(messages)
```
运行 → 测试通过 → 绿灯 ✅

**步骤 3：重构（改进设计）**
- 添加边界校验
- 提取 `Harness` 类
- 保持测试通过

## 关键设计决策

### 为什么用普通函数而不是抽象基类？

```python
# ❌ 过度设计
class ModelInterface(ABC):
    @abstractmethod
    def call(self, messages: List[Message]) -> str:
        pass

# ✅ 简单有效
Model = Callable[[List[Message]], str]
```

**原因：**
- Python 是 duck typing，只要可调用就行
- 减少样板代码
- Fake Model 只需要一个函数，不需要继承

### 为什么先用 Fake 再接真实模型？

**顺序：**
1. Fake Model → 验证执行链逻辑
2. 真实 Model Adapter → 验证网络协议
3. 手工集成测试 → 验证端到端

**好处：**
- 先确保骨架对，再填充网络细节
- 失败时容易定位（逻辑问题 vs 网络问题）

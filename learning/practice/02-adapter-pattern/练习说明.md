## 学习目标

通过实现一个简化的模型适配器，理解：
- 适配器模式如何解耦接口
- 如何用测试替身（Fake Opener）测试网络代码
- 错误边界和异常转换

## 练习说明

ClawBot 使用 `OpenAICompatibleModel` 作为适配器，把 OpenAI API 适配到 Harness 的 `messages -> string` 协议。

现在你要实现一个简化版本，理解适配器的核心逻辑。

        """
        api_key: API 密钥

        5. 提取文本内容

2. Authorization 头正确（Bearer token）
3. 能从响应中提取文本
4. 网络错误时抛出 `AdapterError`

## 核心学习点

### 1. 为什么 opener 可以注入？

**没有注入：**
```python
def __call__(self, messages):
    response = urlopen(request)  # 硬编码，必须真实请求
```

**有注入：**
```python
def __call__(self, messages):
    response = self._opener(request)  # 测试时注入 fake_opener
```

**好处：**
- 测试不需要网络
- 可以模拟各种响应（成功、失败、超时）
- 测试快速且确定

### 2. 为什么需要 AdapterError？

把所有底层异常（HTTPError, JSONDecodeError, KeyError）统一成一个：

```python
try:
    response = self._opener(request)
    data = json.loads(response.read())
    return data["choices"][0]["message"]["content"]
except Exception as e:
    raise AdapterError("request failed") from e
```

调用方只需要捕获 `AdapterError`，不需要知道底层细节。

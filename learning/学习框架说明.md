# ClawBot 学习框架

这是一个可迁移的学习框架，支持 AI 模型无缝切换，结合企业案例和实战练习，帮助积累面试和简历素材。

## 框架特点

### ✅ AI 模型无关
- 任何 AI（Claude/Codex/其他）都能读取 `state.json` 继续教学
- 学习进度和笔记独立于具体模型
- 不同模型的反馈可以对比学习

### ✅ 企业案例驱动
- Netflix Chaos Engineering
- Uber Michelangelo Platform
- Alibaba（待补充）
- 每个案例都关联到项目实际代码

### ✅ 面试准备完整
- 简历描述模板
- 项目介绍话术（90秒版 + 30秒版）
- 技术深度问答
- 常见追问准备

### ✅ 动手练习验证
- 每个概念都有对应练习
- 自动验证脚本
- 参考答案对比

### ✅ 完全可迁移
- 复制 `learning/` 文件夹到任何项目
- 重置 `state.json` 即可开始新学习
- 框架本身可以作为模板

## AI 模型切换指南

### 任何 AI 执行 Skill 时的流程

1. **读取状态**
   ```json
   // learning/state.json
   {
     "current_phase": "phase2-adapter",
     "current_workbook": "learning/workbooks/phase2-workbook.md"
   }
   ```

2. **读取 Workbook**
   - 了解已经学习的内容
   - 查看未回答的问题
   - 继续深入教学

3. **加载教学内容**
   - `curriculum/{phase}/concepts.md` - 概念讲解
   - `curriculum/{phase}/enterprise-case.md` - 企业案例
   - `curriculum/{phase}/interview-qa.md` - 面试准备

4. **更新进度**
   - 保存到对应的 workbook
   - 更新 `state.json` 的时间戳

### 切换模型示例

**场景：** 从 Claude 切换到 Codex

```python
# Claude 上次学到这里（写入 state.json）
{
  "current_phase": "phase2-adapter",
  "last_updated": "2026-09-05T10:30:00Z"
}

# Codex 执行 /learn 继续
# 1. 读取 state.json → 知道在学 phase2
# 2. 读取 phase2-workbook.md → 看到已经回答的问题
# 3. 从下一个未回答的问题继续
# 4. 可以对比 Claude 之前的反馈，提供新视角
```

## 三个核心 Skills

### 1. `/learn` - 教学模式

**功能：**
- 讲解核心概念
- 展示企业案例
- 提问并评价回答
- 推荐练习

**输出格式：**
```markdown
## 📚 Phase X: [主题]

### 核心概念
[讲解...]

### 🏢 企业案例：Netflix
[案例分析...]

### ❓ 思考问题
Q: [问题]
```

### 2. `/practice` - 练习模式

**功能：**
- 提供结构化练习
- 自动验证答案
- 给出改进建议
- 记录到 workbook

**使用：**
```bash
/practice 开始       # 推荐当前阶段的练习
/practice 验证       # 验证完成度
/practice 提示       # 获取提示
/practice 答案       # 查看参考答案
```

### 3. `/interview-prep` - 面试准备模式

**功能：**
- 生成简历描述
- 准备项目介绍话术
- 模拟技术面试
- 企业案例关联

**输出：**
- 简历片段（可直接复制）
- 90秒项目介绍
- 常见问题回答
- 技术深度问答

## 迁移到新项目

### 步骤 1：复制框架

```bash
# 复制整个 learning 目录
cp -r ClawBot/learning NewProject/learning
cp -r ClawBot/.claude/skills NewProject/.claude/skills
```

### 步骤 2：重置状态

```bash
cd NewProject/learning
echo '{"current_phase": null, "completed_phases": []}' > state.json
```

### 步骤 3：调整内容

1. 修改 `curriculum/` 中的代码引用
2. 更新企业案例中的项目关联
3. 调整练习以匹配新项目

### 步骤 4：开始学习

```bash
/learn 开始 phase1-minimal-loop
```

# 教学 Skill

这个 Skill 提供结构化的学习路径，帮助你深入理解 ClawBot 项目，同时积累面试和简历素材。

## 工作流程

### 1. 读取学习状态

首先读取 `learning/state.json` 确定当前进度：
- 正在学习哪个 Phase
- 已完成哪些主题
- 当前 workbook 位置

### 2. 加载教学内容

根据 `current_phase`，从 `learning/curriculum/{phase}/` 加载：
- `核心概念.md` - 核心概念讲解
- `企业案例-Netflix.md` - 真实企业案例
- `面试问答.md` - 面试问答

### 3. 互动教学

**教学模式：**
1. 讲解核心概念（结合 ClawBot 实际代码）
2. 展示企业真实案例（Netflix, Uber, Alibaba 等）
3. 提出思考问题
4. 等待学习者回答
5. 评价答案并指出改进方向

**重要：** 学习者的回答和 AI 反馈都记录在 `learning/workbooks/{phase}-workbook.md` 中

### 4. 推荐实践

指向 `learning/practice/` 中的动手练习，帮助巩固概念

### 5. 更新状态

教学结束后更新 `learning/state.json`：
- 更新 `last_updated` 时间戳
- 记录模型信息（便于追踪但不依赖）
- 标记完成的主题

## AI 模型切换处理

**关键设计：任何 AI 都能无缝接续**

当 Claude/Codex 或其他模型执行本 Skill 时：

1. **必须先读取：**
   - `learning/state.json` - 了解当前进度
   - 对应的 workbook - 了解学习者已经掌握的内容和思考

2. **继续教学：**
   - 不重复已完成的内容
   - 基于学习者在 workbook 中的回答继续深入
   - 可以对比之前模型的反馈，提供新视角

3. **保持一致性：**
   - 使用相同的教学结构
   - 面试准备内容格式统一
   - 企业案例关联保持清晰

## 使用方法

**开始新主题：**
```
/learn 开始 phase3-tool-loop
```

**继续当前主题：**
```
/learn 继续
```

**复习特定概念：**
```
/learn 复习依赖注入
```

**查看学习进度：**
```
/learn 进度
```

## 输出格式

教学过程中使用清晰的结构：

```
## 📚 Phase X: [主题名称]

### 核心概念
[讲解...]

### 🏢 企业案例：[公司名]
[案例分析...]

### 💡 与 ClawBot 的关联
[代码位置和设计对应...]

### ❓ 思考问题
Q: [问题]
[等待你的回答]

### 📝 记录到 Workbook
[你的回答会被保存到对应的 workbook]

### ✅ 下一步
- [ ] [待完成项...]
```

## 面试准备整合

每个主题学完后，自动在 workbook 中生成"面试可以这样讲"部分：
- 技术要点总结
- 企业案例关联
- 简历描述模板
- 常见追问和回答思路

## 注意事项

1. **workbook 是学习者的笔记本**，AI 只追加内容，不删除学习者的回答
2. **state.json 是单一真相来源**，任何模型都必须先读取它
3. **企业案例要具体**，包含公司名、技术细节、可验证的信息
4. **面试模板要实用**，直接可以用在真实面试中
